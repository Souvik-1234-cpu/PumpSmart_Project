These are COMPLETED audit results from M6.5 execution.
They are NOT pending work. They are design constraints
that M6B sequence generation and M7/M8 architecture MUST respect.

Finding 1 — OVERLOADING IS THERMAL-DOMINANT:
  Gate3=0.00%, MAE=0.093 (below M4 threshold=0.110058).
  M4 LSTM-AE cannot detect overloading via single-window threshold.
  → M6B Group D (overloading_cyclic): generate with steeper
    TempSV sawtooth so trend accumulator fires within 15 min.
  → M8 Mech C (Temp.SV Spearman drift ≥0.70) = PRIMARY detection.
  → Gate M8-7: overloading TPR ≥80% via Mech C ONLY.
  → M7: mean_err_TempSV expected SHAP rank 1 for overloading.

Finding 2 — SEAL FAILURE IS A SLOW HYDRAULIC FAULT:
  Gate3=29.17%, gradual Pres.SV decline only 29% windows exceed threshold.
  → M6B Group D (seal_failure_fast): must show faster PresSV drop
    (large-Δ in ≤20 steps) to increase M4 Gate3 pass rate.
  → M8 Mech C (Pres.SV Spearman drift ≥0.70, negative) = PRIMARY.
  → Gate M8-9: WATCH state ≤20 min. Gate M8-10: PresSV fires before WARN.
  → M7: err_slope_PresSV expected in SHAP top-3 for seal_failure.

Finding 3 — BEARING SEAM DISCONTINUITY (5.75% sequences):
  dX/dt discontinuity at t49→t50 (spike seed / M5 physics seam).
  Sequences kept in training — represent realistic shock events.
  → M8 attention must NOT peak at t49–t50. Gate M8-8.
  → M12 bearing configs: use smooth physics sequences only (no spike seeds).

Finding 4 — FISHER RANK 1 = PmpSV_mean:
  Validates channel weight direction for M8.
  → M8 weights confirmed: Mot.SV=2.5, Pmp.SV=2.5, Pres.SV=2.5 (up from 2.0)
  → Low weights confirmed: Temp.SV=0.5, Mot.TV=0.3, Pmp.TV=0.3
  → Mech C monitors thermal channels UNWEIGHTED via Spearman.
  → M6B compound chains must produce strong PmpSV signatures to be learnable.

Finding 5 — CAVITATION BYPASSES WATCH/WARN → DIRECT DANGER:
  Gate3=100%, MAE=0.675 (6.1× above threshold).
  → M6B Group D (cavitation_intermittent): MAE must stay above
    threshold even in low-NPSHa oscillation phase (not drop to 0.093).
  → M8: cavitation always → DANGER in 1 window. No trend needed.
  → Report overloading TPR and cavitation TPR SEPARATELY in M8.

Finding 6 — NORMAL GATE3 PROBE 86.67% ≠ FALSE ALARM PROBLEM:
  Probe sampled 30 edge-case windows deliberately.
  Full M4 validation: 0.55% FPR (8/1,457 windows). Correct.
  → Gate M8-2 FPR must use full 9,711-window pool ONLY.
  → DO NOT adjust M4 threshold based on probe result.

Track 2 — Compound fault (BIAS-04):
  Early stage  → fault_stage=early, type=unknown → MONITOR
  Confirmed    → SECOND signature on CAUSALLY UNRELATED channels
                 → CRITICAL (compound label)

Physics discriminator (is it causal propagation or independent?):
  MotSV rises → MotTV rises 30 steps LATER    = SINGLE (thermal lag)
  MotSV rises + PresSV drops SIMULTANEOUSLY   = COMPOUND (uncorrelated)

  PresSV drops + MotTV rises SIMULTANEOUSLY   = COMPOUND (no physical link)

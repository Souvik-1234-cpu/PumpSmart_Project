DETECTION ARCHITECTURE — BIAS RESOLUTION (v14.1)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Four detection layers run in cascade — M8 + M10:

Layer 1 — LSTM-AE 50-step window (M8):
  Detects: "Is THIS window anomalous?"
  Memory: 50 steps only (encoder hidden state resets each window)
  Blind to: cross-window trends
  Threshold: 0.110058 (LOCKED)

Layer 2 — Fuzzy Logic + Rolling Accumulator (M8):
  Detects: "Has anomaly score been elevated across recent windows?"
  Memory: last 20–40 windows
  Catches: faults where MAE = 0.07–0.10 consistently across windows
  States: WATCH (score 2.0–3.5) → WARN (3.5–5.0) → FAULT (5.0+)

Layer 3 — CUSUM Runtime State (M10): ← NEW v14.0
  Formula: S_n = max(0, S_{n-1} + (mae_channel_n − μ0) − k)
  Reference μ0: M3 cluster baseline MAE per channel (READ-ONLY)
  Allowance k: 0.5 × (threshold − μ0) per channel
  Channels monitored: mae_MotSV, mae_PresSV, mae_TempSV
  Fires when S_n exceeds control limit (configurable, default=5.0)
  Catches: label 21 (bearing_wear_gradual) at ~Week 5.5 (bearing ~30% degraded)
  State: persistent across API calls in M10 runtime memory
  Resets: only on explicit operator acknowledge or pump restart
  IMPORTANT: CUSUM is NOT in M6.5r feature matrix — train-serve skew risk
             if added. CUSUM lives in M10 deployment layer ONLY.

Layer 4 — Rolling Baseline Comparator (M10): ← NEW v14.0
  Monitors: 30-window rolling mean of err_slope_MotSV, err_slope_PresSV
  Reference: M3_normalization_config.json normal baselines (mean, σ)
  Control limit: rolling mean > μ_normal + 2σ_normal → TREND ALERT
  Catches: pre-threshold drift weeks before Layer 1 fires
  State: persistent across API calls.
  Output: feeds bearing_wear_gradual advisory:
          "Plan bearing inspection within 7–14 days."
  Physics basis: rising rolling slope = da/dN trend (Paris law) —
                 consistent with ISO 7870 Shewhart control chart logic.

Two parallel confidence tracks run simultaneously:

Track 1 — Single fault (BIAS-01):
  Early stage  → fault_stage=early, type=unknown → MONITOR
  Confirmed    → ONE signature strengthens → ALERT (single label)

Track 2 — Compound fault (BIAS-04):
  Early stage  → fault_stage=early, type=unknown → MONITOR
  Confirmed    → SECOND signature on CAUSALLY UNRELATED channels
                 → CRITICAL (compound label)

Physics discriminator (is it causal propagation or independent?):
  MotSV rises → MotTV rises 30 steps LATER    = SINGLE (thermal lag)
  MotSV rises + PresSV drops SIMULTANEOUSLY   = COMPOUND (uncorrelated)
  PresSV drops → PmpSV spikes AFTER           = SINGLE (seal→cavitation chain)
  PresSV drops + MotTV rises SIMULTANEOUSLY   = COMPOUND (no physical link)

Three M10 API output states:
  State 1: fault_stage=early, fault_type=unknown → action: MONITOR
  State 2: fault_stage=developing, compound=False → action: ALERT
           (single label, e.g. bearing_wear)
  State 3: fault_stage=developing, compound=True  → action: CRITICAL
           causal_chain=[bearing_wear→overloading]
           (multi-label UI display, single integer label internally)

      not physical MPa√m units. Document as such in fault_rules_v3.json.
      label 21 (gradual): ΔK range = 0.05–0.25 (small ΔK = slow crack growth)
      label 1  (standard): ΔK range = 0.25–1.0 (moderate-high crack growth)

  cavitation (labels 3, 8, 10, 12, 18):
    Rayleigh–Plesset bubble collapse dynamics
    Onset condition: NPSHa < NPSHr
    NPSHa = (Ps − Pv)/(ρg) + Vs²/(2g)
    label 18 (intermittent): NPSHa oscillates around NPSHr boundary
      burst_interval drawn from Uniform(15, 30) steps

  seal_failure (labels 4, 8, 10, 15, 19):
    Standard seal failure (labels 4, 15): gradual hydraulic leak, slow PresSV decline
    seal_failure_fast (label 19): RAPID hydraulic discharge through enlarged
      seal gap / effective orifice area. Governing equation:
        Q_leak = Cd × A_orifice × sqrt(2 × ΔP / ρ)
      where Cd ≈ 0.61 (sharp-edged orifice), A_orifice increases
      rapidly with seal blowout → large-Δ PresSV collapse in ≤20 steps.
      NOTE: Hagen–Poiseuille (laminar pipe flow, Re<2100) does NOT apply
      to seal blowout — flow regime is turbulent orifice discharge.
      Do NOT use H-P equation for label 19 in fault_rules_v3.json or M6B script.

  overloading (labels 5, 7, 11, 20):
    Navier–Stokes viscous dissipation → thermal rise
    label 20 (cyclic): TempSV thermal sawtooth
      cyclic_baseline_drift > 0.0002/window enforced
      Temp.SV Spearman > 0.70 on baseline-detrended signal

  Joukowsky pressure surge (label 8: cavitation→seal_failure):
    ΔP = ρ × a × ΔV
    At nameplate: ρ=1000 kg/m³, a≈1200–1400 m/s, ΔV≈1.3–1.6 m/s
